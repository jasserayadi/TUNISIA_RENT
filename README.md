\# TounesRent 🇹🇳



\*\*Tunisian Rental Price Estimation Platform\*\* — full-stack app that estimates apartment rents across Tunisia using machine learning.



\## Features



\- 🤖 ML-powered rent estimation (Random Forest)

\- 📍 Tunisian governorates + cities

\- 💰 Price range (min / max)

\- 🔍 Advertised price comparison

\- 🏠 Similar properties

\- ⭐ AI recommendations

\- 📊 Statistics dashboard

\- ➕ Add property

\- 🌗 Light / dark mode
